Listing "Git" as a skill is common; showing how you used it is rare. Useful evidence: a public repository with a clear commit history; branches and pull requests, even on a solo project; a README that explains setup; issues you opened or fixed; code review comments you gave or received in a team project.

For collaboration, describe your part in group work precisely: "Owned the data pipeline in a 4-person team; reviewed teammates' pull requests." Asking classmates to test your project and acting on their feedback also counts and is worth a line.

Keep the repository tidy before you share the link: no secrets or personal data in the history, no large data files, and a description of what works and what does not.
