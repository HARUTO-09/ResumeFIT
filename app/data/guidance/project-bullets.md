title: Writing strong project bullets

A good project bullet has three parts: what you did, the tool you used, and the result. Start with a verb: built, trained, designed, tested, deployed, reduced, automated.

Weak: "Worked on a machine learning project for image classification."
Stronger: "Trained a CNN in PyTorch to classify chest X-rays; 91% accuracy on a held-out test set."

Use two to four bullets per project. Give one bullet to the model or core logic, one to engineering (API, database, tests, Docker), and one to the result or what you learned from a failure. Put the most relevant project for the job first. Drop bullets that only list course topics. Write "I" out of the sentence and keep each bullet to one or two lines.
