---
title: Structuring the skills section
source: Written for ResumeFit by the project author; original text, free to reuse in this project
version: 1
---
Group skills so a reader can scan them: Languages; Libraries and frameworks; Tools and platforms; Databases. Put the skills this job description asks for early in each group, as long as you really have them.

List a skill only if you could answer two interview questions about it or point to where you used it. Every important skill should appear again in a project or experience bullet, because a skill named once with no evidence carries little weight.

Use the common name and spelling ("scikit-learn", "PostgreSQL", "REST APIs") so keyword screens match it. Avoid rating yourself with stars or percentages. Leave out skills everyone has, such as web browsing or typing, and remove tools you touched once in a lab.
