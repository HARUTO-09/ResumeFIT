A working link is strong evidence because the reader can check it. Put your GitHub profile and, where you have one, a live demo link in the contact line or beside the project.

Before sharing a repository, make sure the README states what the project does, how to run it, how it was tested or evaluated, and its known limits. Pin your two or three best repositories. Remove or make private anything unfinished that you would not want to be asked about.

Check that demo links still load; free hosting tiers sleep or expire. If a demo is slow to wake, say so in the README. Type links out as plain text so they survive text extraction, and keep them short.
