Job descriptions increasingly mention data privacy, security and responsible AI. Students can show this with concrete design choices.

Privacy: collect only the data you need; remove names and contact details before logging or sending text to an outside model; let users delete their data; set a retention period.

Security: keep keys in environment variables, never in the repository; hash passwords; validate uploaded files by content and size.

Responsible AI: show how a score is built instead of presenting a bare number; test that changing only a name does not change the result; state what the system should not be used for.

On the resume: "Redacted personal data before model calls; added a test that the score is unchanged when only the candidate's name changes."
