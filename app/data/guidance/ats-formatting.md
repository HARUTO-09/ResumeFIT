---
title: Formatting a resume so screening software can read it
source: Written for ResumeFit by the project author; original text, free to reuse in this project
version: 1
---
Applicant tracking systems extract text from your file before a person sees it. If extraction fails, your skills are not counted.

Keep to one column; text in side columns and tables is often read out of order. Use standard headings: Skills, Projects, Experience, Education. Export a text PDF from your editor instead of a scanned image; if you cannot select the text with a mouse, software cannot read it either. Avoid text inside images, icons for contact details, headers and footers for important content, and unusual fonts.

Use simple bullet characters and consistent date formats. Name the file with your name and the role. Test it: copy all text from the PDF into a plain text editor and check that it is complete and in order.
